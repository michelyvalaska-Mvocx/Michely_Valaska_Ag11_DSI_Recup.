# Monitoramento do Reservatorio e aplicação da biblioteca colorama

Atividade de Recuperacao - DS1
Aluna: Michely Valaska
Turma: DS1 - Ag11

aplicar a biblioteca colorama

## O que o programa faz

O programa monitora o nivel de agua de um reservatorio.
Ele recebe o nivel atual, calcula a media e mostra a situacao:

Nível 1 - Muito baixo (crítico) vermelho
Nível 2 - Baixo - amarelo
Nível 3 - Médio -  verde
Nível 4 - Alto - ciano
Nível 5 - Muito alto (alerta)-  azul

## Como executar

1. Abrir o arquivo Michely_Valaska_Ag11_DS1_Recup.py no VS Code
2. Clicar em Run
3. Digitar os valores pedidos
